# TUI curl installer design

Approved by the user on 2026-10-24: install the TUI and its private Node/Host runtime with one public curl command; provide an optional client-only mode. Installation starts no Host.

The public distribution repository owns `install-tui.sh`. It defaults to the coordinated `0.2.0-rc.3` assets rather than GitHub's Latest endpoint, which currently selects RC.2. It detects macOS/Linux and ARM64/x64, downloads the portable TUI and matching Host archive, verifies their exact SHA-256 entries, and installs production dependencies with the bundled npm and scripts disabled. No sudo, system Node, private checkout, compiler, or Python is required by the installer. Client-only mode uses an existing compatible Node/npm and downloads no Host.

Install under `${XDG_DATA_HOME:-$HOME/.local/share}/aesir-cli` by default, with an optional explicit prefix. Each installation has a separate version directory. Validate it before atomically changing the active version. Expose `aesir` and `aesir-tui` inside the prefix's own bin directory; preserve existing launchers elsewhere. Configure bash/zsh PATH once unless requested otherwise. Unknown shells receive explicit PATH instructions. Preserve all session data, credentials, model settings, and TUI preferences.

The launcher uses the installed client's own connection-selection helpers. Explicit flags, existing-Host environment variables, and saved connections retain precedence. Only a self-contained installation without an existing selection defaults to its bundled Host, through a stable active-version path. The client still requests folder trust on managed launch. Client-only installations retain the normal connection chooser. Desktop instance discovery and selecting Desktop's ordinary main window are separate product changes and are not claimed by this installer.

Stage downloads and npm installation in a private directory. Fail visibly on unsupported targets, checksum errors, missing assets, dependency-install errors, or ownership conflicts. Do not activate a partial installation. Use a per-prefix lock to prevent concurrent updates. Retain previous installed versions rather than deleting files that an active process may use. Installation and reruns make no model request and launch no Host.

Verification covers all four target mappings, execution without global Node/npm, existing connection precedence, paths containing spaces, repeat installation, checksum and package-manager failures, command conflicts, PATH idempotency, and cleanup. A separate smoke installs actual public assets in a clean home and runs `aesir --version` and the keyless built Host capability smoke. Public CI runs the regression tests and live smoke natively on the four supported targets. Documentation supplies the curl command, options, requirements, update/removal instructions, and current Desktop limitations.
